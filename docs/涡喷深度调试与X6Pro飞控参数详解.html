涡喷第一部分 · SW400Pro 深度调试

1.1 调试路线图与准备

核心原则：先试车台、后装机。玄云说明书明确要求——把发动机装上飞机前，先在地面试验平台完成至少一次启动与运行，以熟悉流程、验证油路电路。新机第一运行要让 ECU 学习油门，这一步在试车台上做最安全。

调试路线（6 大步）

① 连接自检 → ② GSU 校准遥控 → ③ 点火前部件测试 + 温度校准 → ④ 首次启动（ECU 学习） → ⑤ 参数核对与特性设置 → ⑥ 重复启动验收（连续 3 次一次成功）。

试车台准备清单

项目要求
固定专用试车台或抱箍固定在木质纵梁上，推力方向无遮挡；进油口旋转到 12 点位置
ECU 电源4S 锂电池（建议 16.8~20V、≥3000mAh、独立于飞控电源）；接收机常规 2S 供电
灭火器CO₂ 灭火器 ≥5kg（禁用泡沫/干粉/水基）
安全区进气方向 3m、左右 5m 内无人无杂物；喷口后方留 8~10m 净空；严禁室内
人员佩戴耳罩、安全眼镜；操作者站在侧面，一人专职持灭火器
油料航空煤油（或柴油）+ 3%~5% 玄云/美孚飞马二号润滑油；油路装费斯托油滤
防气泡油箱主油箱与油泵（ECU）之间必须串接防气泡油箱，先排空其内部空气

1.2 连接自检与遥控校准

连接自检（三听）

  • 上电音乐：所有线束接完后 ECU 发出"滴-滴滴-滴滴滴"→ 连接完好。
  • 待机"滴"：连接后无指令时 ECU 间歇性"滴"提示 → ECU 活着。
  • GSU 连接成功界面：杜邦头黄色线对齐插入后 GSU 正常显示。

GSU 校准遥控（三步法，首次必做）

打开油门锁 → GSU"校准遥控"：①"最大"——油门杆推最大，OK；②"待机"——油门杆收回，OK；③ 关油门锁后"最小"——油门杆最小，OK。回初始界面推油门，RC 数值随手柄变化即成功。

遥控器协议：Futaba 遥控器必须设定反相，JR 正相。启动时油门微调必须先关到最低再开到最高才能进入准备启动状态（微调在最低时推满油门电机转动但不会进入启动程序——这是正常的防误动逻辑）。校准的本质是让 ECU记住三个 PWM 位置：停机档 / 怠速档 / 100% 油门档。

1.3 点火前五项测试与温度校准

测试项操作合格判据失败处置
主油泵（排气充油）长按 GSU"测试主油泵"；建议先拔下发动机端油管燃油充满整根油管；液面刚到发动机入口立即停止不上油→查油箱通气管是否打开、快接头是否漏气；富油→拔管放油后再试
点火电磁阀点按测试"嗒嗒嗒"声无声→返厂
主电磁阀点按测试"嗒嗒嗒"声无声→返厂
启动电机点按测试叶轮顺时针平稳转动打滑/异响→清理压气轮螺母与离合器胶圈接触面燃油或换胶圈
火头GSU 测试火头界面电流有变化；尾喷口可见亮点无电流/无亮点→"火头故障"，返厂

1.4 首次启动四阶段详解（对照 GSU 状态）

阶段ECU 在做什么GSU 上你看什么异常信号
准备启动收到启动指令（微调拨到启动档），极短状态字变"准备启动"无反应→遥控校准/开关通道未接好
点火火头通电、点火电磁阀开、启动电机带到 3,000rpm 点火转速转速爬升、温度开始上升温度 20 秒无变化→"超时"；只闻燃油味不见升温→富油/火头
预热电机继续带到 4,000rpm（+1000~2000rpm），温度继续升温度稳定爬升温度不升反降→"温度低"；供油不足或气泡
加速电机带转速冲向离合器分离转速 14,000rpm，随后电机脱开，温度已过 100℃转速快速拉起，点火成功转速上下跳动/掉转→"转速不稳定"；到 14,000rpm 附近听电机是否干脆脱开
运行自持运转，油门 0→100% 对应怠速 35,000→97,000rpm怠速稳定，各读数平稳怠速漂移→查气泡、通气管、油泵标定
首次启动的关键动作（说明书原文）：新机第一次运行时必须缓慢加大油门至最大转速并稳定运行——让 ECU 学习最高转速对应的油泵功率（GSU 可查"已学习的油泵最高电压"）。学习过程在加速中出现转速上冲/回摆是正常的，但出现持续超温（GSU 红色报错）立即把微调拨回停机档散热。首次试车不必飞转速红线，怠速→60~70% 油门往返数次即可完成学习。
喷火判据与处置：启动时机尾喷口出现明火且持续 3 秒以上即为"喷大火"（多次启动失败或油箱压力过大所致）→ 立即关闭油路球阀，火焰随即熄灭，再做停机散热，之后查找富油原因（排气不充分/微调位置/油泵电压）再试。

1.6 特性参数与安全逻辑（ECU Tools → 设置参数 → 特性参数栏）

特性出厂默认含义与建议
遥控信号丢失监测开启（不勾选"取消"）开启时：信号中断 2.5 秒发动机直接停车并自动冷却。涡喷固定翼装机建议保持开启——失控时宁可熄火滑翔返场，也不要让一台无人管控的发动机继续推力。若用飞控串口/自动任务控制且需要失控后继续动力，才考虑取消，此时安全责任转移到飞控失控逻辑
熄火重启关闭空中熄火后 ECU 自动热重启。有滑翔迫降能力的固定翼建议保持关闭，防止意外点火加剧险情；需开务必先咨询售后
加速冷却按出厂提高冷却电机转速加快散热，连续起降间隔短时可咨询售后开启
转速闭环控制按出厂ECU 以转速为目标闭环供油（对应串口协议的转速控制模式）。PWM 遥控方式即油门开环+保护，默认即可

1.7 关车冷却与试车台验收标准

标准关车流程

  1. 油门杆收到最小 → 等转速回落并稳定在怠速。
  2. 油门微调拨到停机散热档位 → 自动进入"冷却"状态：启动电机以 4,000rpm 恒定转速带风，直到排温 < 100℃ 自动停机。
  3. 意外熄火时：将遥控器置于关车位置，手动方式散热（再拨一次散热档）。
冷却未完成不得断 ECU 电源——涡轮轴承靠余热下的通风保护，热态断电直接减寿命。这也意味着飞行结束后要等 ECU 冷却程序走完再关总电源。

装机前验收标准（全部满足才上机）

  • 连续 3 次冷启动一次成功，GSU 参数曲线（转速/温度/油泵）基本一致；
  • 怠速 3 分钟稳定：转速波动 <±2%、排温稳定、无渗油；
  • 怠速↔70% 油门往返 5 次，加速平滑无喘振、无超温报错；
  • 每次关车均完整走完自动冷却；
  • GSU 无任何红色报错记忆（历史记录查故障码）。

1.8 ECU 与 X6 Pro 的两种接线方案

SW400Pro 信号线自带三路：开关（启停档）、油门（PWM 油门）、RS232（串口协议，支持油门/转速双模式，协议见说明书 5.4 节）。对应两种与飞控的配合方式：

方案 A：PWM 直连（推荐首飞）方案 B：飞控串口控制（进阶）
接法ECU"油门"线→接收机油门通道（或经 X6 Pro 舵机口透传）；"开关"线→接收机一个 2~3 档开关通道ECU RS232→X6 Pro 串口转接线（需玄云/零一定制转接），飞控软件界面回传发动机参数。本机已用 232 转 TTL 模块接好——完整调试方法见 2.9 节
飞控角色飞控只管舵面与导航；发动机完全独立，失控保护依赖 ECU 信号丢失监测（2.5s 停车）飞控可读转速/温度、自动控制油门甚至转速模式（自动航线动力闭环）
优点链路最简单、故障面最小、与厂家默认安全逻辑完全一致数据进日志、支持自动任务动力管理、地面站直读发动机状态
风险飞控自动返航时无法自动收油（人必须在失控后收油门）串口异常时动力失控风险面大，需深入验证协议与失效行为
折中做法（很常用）：ECU 油门线接 X6 Pro 的一个舵机输出口，地面站把该口功能设为 Throttle——正常飞行由遥控经飞控透传控制油门，飞控失控/返航时也能自动收油；启停档仍由独立开关通道掌握，保留"随时断动力的物理手段"。注意此时 ECU 看到的是飞控输出的连续 PWM，飞控失控逻辑里必须明确油门去向（见 2.7 节）。

1.10 数据下载、升级与寿命管理

  • ECU Tools（User）：下载飞行/运行历史数据（每次飞行后建议导出存档，对比"转速-温度-油泵功率"三条曲线是否漂移——漂移是早期故障的最好预警）。
  • Upgrade Tools：ECU 固件升级，从玄云官网下载；升级后必须重新核对参数。
  • 寿命管理：每 25 小时返厂保养（换轴承、清积碳、动平衡）；日常手转转子听"沙沙"声；油滤定期更换；关车必冷透。

飞控第二部分 · X6 Pro 飞控参数详解

2.1 硬件接口与系统接线

X6 Pro 基于 FMU v6X（STM32H753 主控 480MHz + STM32F103 IO 协处理器），双气压计、内置 RM3100 罗盘、三 IMU 带恒温加热与减震，16 路 PWM（M1~M14 杜邦 + M15/16 GH1.25 扩展），ArduPilot/PX4 双固件支持。与本机相关的接口用法（零一官方定义）：

接口本机接法
Power 1~2（DroneCAN 电源口）接 OnePMU（双路冗余电源管理），PMU 另端接主锂电
SBUS IN接收机 SBUS 信号（遥控主通道输入）
CAN1 / CAN2挂 OneRTK（UM982 双天线定位）与 OneASP（DroneCAN 空速计）
GPS&Safety / GPS2GPS1=SERIAL3，GPS2=SERIAL4；可接标准 GPS 或 RTK
TELEM1~3数传链路（OneDLink/OneVDLink）或其它 MavLink 设备（TELEM1=SERIAL1，TELEM2=SERIAL2，TELEM3=SERIAL5）
M1~M14PWM 舵机/设备输出；1~8 由 IO 协处理器控制。本机：副翼×2、升降×2、方向、前轮转向、油门（给 ECU）、起落架 Gear、刹车
TF 卡槽插卡记录飞行日志（≤256G，FAT32）——必须插，调参全靠日志
ETH / I2C / SPI按需扩展（网口吊舱、I2C 空速计等），本机暂不用
PWM 电平：X6 Pro 默认输出 3.3V 电平；信号线超过 75cm 时建议改 5.0V（确认舵机支持）。地面站全参数表搜 BRD_PWM_VOLT_SEL，0=3.3V / 1=5.0V，写入后重启生效。PWM 端子为 2.6mm 间距，推荐 Futaba 3pin 杜邦正角插头。舵机电压检测上限 9.9V，供电勿超。

2.2 固件与地面站

  • 固件：X6 Pro 在 ArduPilot 中与 X6 同一固件目标；固定翼用 ArduPilot Plane 4.7.0（零一官方提供 X6 Pro 固定翼固件包，docs.01aero.cn 下载页；也支持 PX4 1.16+）。刷机用 Mission Planner 或零一版 QGC。

2.4 传感器与外设参数（OnePMU / OneRTK / OneASP）

OnePMU（电源管理）

  • 接口：飞控 Power1/Power2 → OnePMU；默认 DroneCAN 自动配置（UAVCAN_ENABLE=Sensors automatic config，一般不动）。
  • 电池参数：PMU 默认按 6S LiPo 标定——本机若用其它规格，在 MP「DroneCAN」页面找到 PMU 节点（org.ZeroOne.pmu）→ 修改电池节数与单芯电压 → 重启飞控，电压/电流/电量百分比才正确。
  • 电压阈值：BATT_LOW_VOLT（低压报警，建议 3.5V/节×节数）、BATT_CRT_VOLT（临界触发 RTL）。

OneRTK（UM982 双天线）

  • CAN 接入即被飞控识别；出厂默认 Rover（移动站）自动配置。双天线航向：主天线装机头方向，GPS_YAW_OFFSET=0；副天线在前时相应设角度（顺时针增）。验证：MP「分析工具」看 GPS_RAW_INT 的 yaw 与机头指向一致。
  • 差分（厘米级定位）：需地面基准站——MP「RTK/GPS Inject」页连接基站注入改正数，或用数传直发 RTCM。无 RTK 差分时自动降级普通 GPS 精度，不影响安全。
  • 若做地面基准站：先在 DroneCAN 页把 GPS_AUTO_CONFIG=0 再用 UPrecise 软件改 Base 模式（详见零一《Building a Ground RTK Base Station》文档）。

OneASP（空速计）

  • CAN 接入自动识别。地面用嘴/专用气筒轻吹皮托管，MP 空速读数应响应；静止时做空速计校准（校零）。
  • ARSPD_USE=1（空速参与控制）、ARSPD_TYPE 按实际类型。皮托管勿装在螺旋桨滑流/机身乱流区（涡喷机无桨，重点是远离机身附面层与起落架收放扰动）。

2.6 分阶段调参流程（第三轮：按日志走）

  1. 滑跑阶段（不起飞）：Stabilize 模式 30~50km/h 滑跑，验证前轮转向增益、方向舵响应；观察 IMU 振动（MP 状态页 Vibe——X6 Pro 内置减震，一般容易达标，超标先查发动机共振传递/舵机振动）。
  2. 首飞：FBWA 起飞巡航，不追性能——确认姿态跟随柔和可用、无明显振荡即可。落地后下日志：看 RLL/PIT 期望 vs 实际的贴合度。
  3. 增益迭代：姿态振荡→对应 *2SRV_P 减 20~30%；姿态跟不上/软→加 10~20%。一次只动一个轴、一次变化不超过 30%。涡喷翼载大、响应快，宁可慢半拍也不要振荡。
  4. AutoTune（可选）：Plane 支持空中自动调参（AUTOTUNE 模式），但涡喷机上慎用——如使用，务必在足够高度、油门收到怠速附近、设定 AUTOTUNE_LEVEL 较低档，异常立即切 Stabilize 退出。
  5. TECS 验证：定高/RTL 模式平飞，日志看空速与高度是否双双稳住：掉高带加速→TECS_SINK_MAX 过小或俯仰增益低；速度高度齐振荡→能量环过激，先降 TECS 增益。
  6. 失控保护实测：高关遥控器，确认 FS_SHORT（盘旋）→ FS_LONG（RTL）依次触发、油门按预期处理（见 2.7），再人工接管。此测试首飞阶段必做一次。

2.9 ECU ↔ X6 Pro 串口通讯调试（RS232 转 TTL 实机章节）

本章针对实机配置：ECU V4 的 WS16J7 信号插头经"RS232 转 TTL"模块接入 X6 Pro 的串口。目标分两级：第一级遥测读入（ECU 转速/排温/油泵/状态实时显示在地面站并写入飞控日志）；第二级串口控制（飞控直接下发启停与油门指令）。ArduPilot 没有玄云原生驱动，标准做法是用 Lua 脚本在脚本串口上解析协议——X6 Pro（STM32H753、2MB Flash）完全支持。ArduPilot 论坛已有同类先例（"[SWIWIN] How to Get Telemetry Values from Jet Engine ECU"，9600bps 收发遥测）。

① 硬件层核对（已接线，做 5 分钟确认即可）

ECU WS16J7（RS232 定义）接向核对要点
3 脚：232TX（ECU 发）232/TTL 模块 R 侧 → 模块 TTL 侧 TXD？→ 飞控串口 RX方向别接反：ECU 的 TX 必须落到飞控的 RX；确认模块是"RS232 电平↔TTL"转换（MAX3232 类）还是 TTL 直通——用万用表测 ECU 3 脚空闲电平：持续负压（约 −3~−8V）= RS232 电平，需转换模块；≈0/3.3V 摆动 = TTL 直通
5 脚：232RX（ECU 收）模块 TTL 侧 RXD ← 飞控串口 TX只做遥测可不接；要串口控制必须接
4 脚：GND模块 GND → 飞控 GND必须共地——不共地是最常见的"有电压但全是乱码"原因
1/2 脚：开关（启停 PWM）保留接独立开关通道无论串口方案走到哪一级，物理启停开关永远保留
6/7 脚：Throttle（PWM 油门）保留现状（接收机或飞控油门口）串口控制成熟前不要拔
接线原则：转接模块插头方向按厂家提示对齐（杜邦头棕色线对齐）；模块供电取 3.3V/5V 均需确认模块规格；飞控端线长 >75cm 时注意 PWM 电平设置（本章不涉及 PWM 输出，但同机其它长舵机线按 2.1 节设 BRD_PWM_VOLT_SEL=1）。

使用说明：若上电后收不到帧，先改脚本头部 STOP_BITS = 2 再试（ZK 协议停止位 1/2 可配置，论坛实测有 8N2 先例）；仍无数据回到②步抓包定位。引擎状态数值编码（0~19）与错误码（0~18）按 ZK 协议附录 1/2，如与 GSU 显示不一致，以 GSU 为准并对照抓包帧修正映射表。

④ 遥测级验证（第一目标，做到这步就很值）

  1. ECU 上电不起动：地面站出现 ECU_RPM=0、ECU 状态、动力电电压 等命名浮点，且数值与 GSU 一致。
  2. GSU"测试主油泵"时：地面站油泵电压同步变化（验证实时性）。
  3. 起动到怠速：地面站 RPM/EGT 与 GSU 对读，误差在换算精度内一致。
  4. 落地后日志核对：MP 日志中 NAMED_VALUE_FLOAT 有全程 ECU 曲线，与 ECU Tools 导出的历史数据对得上。
Mission Planner 查看回传的 4 个位置：① 飞行数据（Flight Data）→ 左下「状态 / Status」标签：列表中找 ECU_ 开头的项（ECU_RPM / ECU_EGT / ECU_STATE / ECU_PUMP / ECU_VBAT 等），ECU 上电即实时刷新；② 「消息 / Messages」标签：脚本推送的文字——"ECU-Lua: telemetry OK, proto vN"、状态变化（如"ECU: [11] 运行 RPM=35000 EGT=500"）、错误与断流报警都在这里；③ 「快捷 / Quick」标签：双击数据区可把 ECU_RPM 等加入自定义仪表列表；④ 日志：脚本每 1 秒写一条 ECU 日志消息（RPM/EGT/STAT/ERR/PUMP/VBAT/THR），飞行后用 MP「数据闪存日志」下载，在日志浏览/图表里选 ECU 消息即可绘制曲线。

⑤ 串口控制级（进阶，充分地面验证前不上机）

  • 脚本发 ID1（SW=3，Throttle 0~1000）即可完全接管油门；SW=2 待机（超温自动冷却）、SW=1 停止（超温不冷却）；发 ID0 空循环维持链路。
  • 转速闭环：ID6 置 SW+RPM_X、ID7 发目标转速——适合自动任务巡航，但首飞阶段不要启用。
  • 失控安全重构：串口控制生效后，ECU 端"遥控信号丢失 2.5s 停车"监测的是 PWM 遥控信号，不再是你想象中的保险——此时失控兜底责任全部落在飞控失控逻辑上（FS_SHORT/LONG 里明确油门归零或熄火指令由脚本执行）。无论何时保留 1/2 脚物理开关通道直连 ECU 作最后断动力手段。
  • 控制权切换纪律：地面测试时用"遥控油门→串口油门"切换开关（脚本监听一个 RCx_OPTION），每次只允许一种控制源，切换瞬间发 ID0 过渡。

⑥ 串口联调故障排查表

现象最可能原因（按概率排序）处置
完全无数据TX/RX 接反；未共地；波特率不对；ECU 串口输出未使能交叉对调 TX/RX 再试；确认模块-飞控-ECU 三点共地；用 ECU Tools 查波特率；确认协议为"ZK"且 ECU Tools 里串口回传已开
有数据但乱码停止位/电平不对；模块类型不符（ECU 是 TTL 出，插了 RS232 转换）；波特率偏差试 1/2 停止位（论坛实测 8N2 常见）；万用表测 ECU TX 空闲电平判断 RS232 还是 TTL；换波特率扫描 9600/57600/115200

升级路径纪律：遥测级（只读）可以随首飞一起上机；串口控制级必须先经过"台架全流程 ≥10 次切换无误 + 失控注入测试（拔数传/拔遥控看油门去向）"才允许装机。任何时候，1/2 脚的物理启停开关通道是最后断动力手段，永久保留。串口改油门参数（ID4/ID5）需要 ID3 解锁，属于厂家级操作，改前知会玄云售后。
最后强调三条：① ECU 信号丢失监测默认 2.5s 停车——这是涡喷机最强的安全网，改它之前想清楚；② X6 Pro 解锁检查全开，任何红色警告不解锁；③ 首飞阶段的唯一目标是"安全收回来"，参数性能迭代全部放在有日志支撑的后续架次。
