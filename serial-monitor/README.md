# 飞控串口监听工具

MP 插件 `zh-serial.cs`：在「飞行数据」页注入「串口监听」勾选框，打开一个独立窗口，
把飞控串口上的全部收发报文与打印内容显示出来。

## 两种数据源（关键设计）
| 模式 | 原理 | 用途 | 限制 |
|---|---|---|---|
| **MP 当前连接** | 挂 `MainV2.comPort.OnPacketReceived` / `OnPacketSent` 事件 | 零配置，MP 连上就能看；能看到**发送方向**（MP 发给飞控的请求） | 只包含 MP 解析成功的 MAVLink 报文，看不到物理层垃圾字节 |
| **独立串口** | 自己开 `System.IO.Ports.SerialPort` 读字节流，自行解 v1/v2 帧 | 可以听 MP 没连的串口（第二路 TELEM、USB-TTL 旁路抓包）；能看到 ASCII 原始打印 | 该串口必须未被 MP 占用；不校验 CRC（错帧可能误判） |

## 功能清单
1. 报文列表：时间 / 方向 / 消息名 / ID / sysid:compid / seq / 帧长 / 内容摘要
2. 选中一行 → 下方显示全部字段（结构体反射展开）与十六进制 dump（含 ASCII 列）
3. 打印页：`STATUSTEXT` 按严重级别着色（紧急/严重/错误红、警告橙、注意蓝），串口 ASCII 行青色
4. 过滤：关键字（逗号分隔，匹配消息名或内容）、方向（全部/仅接收/仅发送）、只看文本
5. 暂停 / 清空 / 保存日志（TSV，可导入 Excel）/ 导出原始帧（.bin，可喂给其它 MAVLink 工具）
6. 独立串口模式：枚举 COM 口、波特率下拉、**自动扫描波特率**（逐个试，命中即开）
7. 状态栏：收/发/文本/丢弃计数 + 实时速率；源标签显示 `COM3 @ 57600`
8. 右键菜单：复制选中行、复制全部、导出选中原始帧；窗口可置顶

## 坑与约定（改这个文件前必读）
- **编译失败静默不加载**：MP 对成功/失败打同样 INFO 日志，错误只在 `PluginLoader.ErrorInfo`。
  排查用 `zh-diag.cs` → `C:/ProgramData/Mission Planner/zh_plugin_errors.txt`。
- **收包线程不能碰控件**：过滤条件在 UI 线程拍快照（`fltTextOnly/fltDir/fltText`），
  收包线程只读快照；直接读 `CheckBox.Checked` 跨线程会炸。
- **UI 不能被灌爆**：报文入 `pending` 缓冲（上限 3000），200ms 定时批量上屏，超限计数丢弃。
- **列表上限 5000 行**，超出从头部删，避免长时间运行内存膨胀。
- **主题前景色**：MP 深色主题会把新建控件文字刷白，方框/表格显式设 `ForeColor = Black`。
- **Dock 顺序**：`TabControl(Fill)` 必须 `SetChildIndex(tabs, 0)`，否则被 Top 面板压住。
- **`Drain()` 必须持 `rbuf` 锁**：v1 帧头 `0xFE`、v2 `0xFD`；`total = 头长 + len + CRC(2) [+13 签名]`。
- 独立串口模式**不需要管理员权限**（和网口 raw socket 抓包不同）。

## 当前版本
v1.0（2026-11-08）：首版，双源监听 + 字段反射 + 打印着色 + 过滤/保存/导出 + 波特率自动扫描。

## 验收点
- MP 连接飞控后勾选「串口监听」，列表出现 HEARTBEAT / SYS_STATUS / ATTITUDE 等，方向「收」「发」都有
- 打印页出现飞控的 PreArm / 模式切换等文本，颜色随级别变化
- 独立串口模式选 COM 口点「打开」，能看到同一条链路的报文；点「自动扫描波特率」能自动命中
- 连续跑 10 分钟不卡、不闪退、内存稳定
