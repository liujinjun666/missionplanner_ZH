一、产品概述

玄云专业版发动机由发动机本体和外置 ECU（V4）控制器两大部分组成。发动机由进气道、压气轮、燃烧室、涡轮、尾喷管等部件组成：气流由进气道吸入，经压气机压缩后进入燃烧室与燃料混合燃烧，高温高压燃气驱动涡轮（涡轮通过轴带动压气机），燃气在尾喷管中膨胀加速后排出产生推力。

  • 发动机本体内集成：TCU（电子控制单元）、无刷启动电机、发动机控制线缆。
  • ECU（V4）内集成：ECU 主控、无刷油泵、电源/发动机控制/信号传输航插接头。ECU 具备故障诊断（故障码存储于内部记忆芯片）、环境监测（温度、气压，适应 -40℃~+50℃）、转速闭环控制、程序可升级等能力。

四、系统连接与线束定义

4.1 连接总览

  • 控制线束：发动机 ↔ ECU。
  • 电源线：航插端接 ECU，另一端 XT60 接 4S 锂电池（插头型号可定制）。
  • 信号线：航插端接 ECU，另一端分 3 根——开关（接收机开关通道）、RS232（PC/飞控串口控制）、油门线（接收机油门通道）。
  • 显示器（GSU）：接 ECU 数据线接口，显示发动机运行数据。
  • 油路：油箱 →（防气泡油箱）→ 油滤 → ECU 内置无刷油泵 → 球阀 → 发动机进油口。
所有线束连接完成后，ECU 发出"滴-滴滴-滴滴滴"音乐提示说明连接完好。连接后无指令时 ECU 会间歇性发出"滴"提示音。

五、安全说明

5.1 安全须知

  • 涡喷是极端机械工作状态，有危险性。第一次启动前必须仔细研读说明书；首次操作请在有经验人员指导下进行。
  • 运转噪音大：严禁心脑血管疾病或对噪音敏感人员进行测试或参观。
  • 严禁在封闭室内启动和运行发动机——大状态排出的燃气可在极短时间内充满密闭空间，可致窒息休克甚至死亡。

5.2 灭火器

  • 试车必须备有二氧化碳灭火器（至少 5kg）。不建议泡沫、干粉或水基灭火器：泡沫/粉尘损坏发动机零件，水基损坏电路板与 ECU。
  • 严禁在易燃、易爆区域内启动运行。
  • 喷大火处理：多次启动失败或油箱压力过大可能导致启动喷大火（机载时机尾喷口出现明火且持续 3 秒以上即视为喷大火）→ 迅速关闭油路球阀，喷火随即消失，再进行停机操作；发动机进入自动冷却后可再次启动。

5.3 噪声防护

测试人员须佩戴听力保护装置；出现头晕耳鸣、恶心、呼吸困难、心律不齐等症状应及时就医。

5.4 安全距离

  • 发动机前方（进气方向）保持 3 米，左右侧保持 5 米。
  • 运转时各方人员必须处于安全区域；进气口吸气"犹如真空状态"，绝对不能把手靠近进气道，手指远离进气口，勿用手指转动压气轮。

5.5 危险区域（厂家定义）

  • 发动机运行时吸入大量空气并排出高温高速气体。进气口禁止摆放任何可能被吸入的物品（线缆、插头、油箱、输油管等）；运行期间严禁进入危险区域。
  • 操作时必须佩戴安全眼镜、耳塞；点火前熟知安全注意事项。
  • 排气温度可高达 750℃，注意周围隔热防温；绝对禁止室内启动。

5.6 火情处理方法

  1. 保持冷静，立即疏散周围无关人员，首先确保人员安全。
  2. 在确保自身安全前提下：立即切断电源、关闭油路球阀，用 CO₂ 灭火器扑救燃烧部位，同时冷却保护油箱与发动机。若飞机外形完整，可将 CO₂ 喷口对准飞机进气道，每隔 0.5 秒间断按压手柄，脉动注入二氧化碳至飞机内部。
  3. 地面有流散燃油时，先设法将飞机拖离危险区域，再扑灭飞机与地面火焰。

六、安装要点

  • Pro 系列配专用固定抱箍：先锁紧抱箍固定发动机，注意不要过度拧紧螺钉，以免外壳变形影响固定效果。
  • 最佳安装位置：旋转发动机使进油口位于 12 点（正上方）位置。
  • 安装到飞机上前，建议先在地面试验平台完成至少一次启动与运行。
  • 切勿私自拆解：发动机一旦拆解必须按规范精密重装，随意组装将使涡喷本体失去平衡，高速运转下会引起严重后果。

七、GSU 显示器使用说明

GSU 是显示与编辑发动机参数的终端，随时可连接/断开，运行中也可调整部分参数。连接时注意两个杜邦头黄色线对应。

7.1 校准遥控器（首次使用必做）

  1. GSU 出厂默认简体中文；初始界面点"OK"进入设置界面。第一次使用主要用"校准遥控"和"测试"两项，其余参数出厂已调至最佳，请勿随意更改。
  2. 校准前确认遥控器油门锁打开。
  3. 选"校准遥控"：单击"最大"→ 油门杆推最大 → 点 OK（完成 100% 油门校准）；单击"待机"→ 油门杆收回 → 点 OK（完成怠速校准）；关闭油门锁，单击"最小"→ 油门杆最小 → 点 OK（完成停机状态校准）。
  4. 回到初始界面，推动油门杆，观察 RC 数值随油门变化即校准成功。

7.2 点火前测试（GSU"测试"功能）

  • 测试主油泵：长按"测试主油泵"至燃油充满油管——注意燃油液面进入发动机立即停止泵油，防止内部富油、启动时喷大火。建议排油操作时把输油管从发动机上拔下，完成后再插回。
  • 测试点火电磁阀 / 主电磁阀：听到"嗒嗒嗒"声音为正常。
  • 测试启动电机：叶轮顺时针转动为正常。
  • 测试火头：GSU 测试界面电流有变化为正常（若测不到电流或尾喷口观察不到亮点，联系售后返厂维修）。

7.3 温度校准

ECU 通过内置温度传感器控制运行；若传感器温度与环境温度相差较多会影响 ECU 判断。在 GSU 运行主界面选择"其它"→"修正温度"，用"+ −"调节至与环境温度一致。

7.4 运行界面读数

运行界面三部分：顶部为上一次运行参数；中部为运行状态（正常绿色、异常红色）；底部为实时数据——转速 / 温度 / 油泵功率 / 遥控油门。玄云 LOGO 下白框显示发动机型号；"时间"为本次运行总时长；"ACC"为怠速到最大转速的时间（可通过加减速曲线调整）。

八、ECU（V4）使用说明

  • 软件升级：玄云官网"技术支持"下载 Upgrade Tools → ECU 经升级器连电脑 → 选择对应版本完成升级。
  • 数据下载：官网下载 ECU Tools（User）→ 打开"历史记录"→ 等待加载 → 保存数据。
  • 修改波特率/参数：ECU Tools（User）→"设置参数"→ 打开设置界面 → 点"修改"。
  • 取消遥控信号丢失监测：ECU Tools → 设置参数 → 特性参数栏勾选。默认未勾选：信号中断 2.5 秒后发动机直接停车并随即进入冷却；勾选后信号中断将执行最后一个指令。同界面还可更改"加速冷却""熄火重启""转速闭环控制"等特性。
出厂时各项参数与特性参数已按发动机性能设置完毕，务必与玄云售后沟通后再改动。

九、发动机调试流程

9.1 启动前检查清单（厂家原文要求）

  • 检查电池电压、电量满足本次启动计划。
  • 准备至少 1 个 CO₂ 灭火器。
  • 确认燃油内已混合 3%~5% 润滑油；油量按预定飞行时间备足。
  • 各线束连接正确，遥控器油门校准正常，地面站/终端数据回传正常。
  • 发动机固定牢固；周围环境安全；进气口附近无杂物；发动机前后无障碍物或易吸入/吹飞物品。
  • 检查发动机外部、压气机叶轮、涡轮、尾喷管完整无损坏。

9.2 供油系统准备

  • 油箱到发动机接好后管内有空气，须先排气充油（建议拔下发动机端油管操作，防止内部积油导致下次启动喷大火超温）。
  • 检查油管干净通畅、无折曲；确保油箱到 ECU、ECU 到发动机段油管充满燃油且发动机内部没有富油。
  • 确保油箱进气阀（通气管）打开——无进气阀或未打开会导致油路不畅、无法启动。

9.3 启动与停止（遥控器方式）

  1. 启动前：GSU 完成遥控校准 → 测试主油泵充油 → 测试电磁阀/启动电机/火头均正常。
  2. 遥控器油门杆最小、油门微调在停机位置；将油门微调调到启动档位，发动机开始点火启动。
  3. 启动过程：准备启动 → 点火 → 预热 → 加速，成功后转速到达并维持怠速（35,000rpm）。
  4. 到达怠速后用油门杆控制转速，100% 油门对应最大转速（97,000rpm）。新机第一次运行必须慢加速至最大转速并稳定运行，让 ECU 学习油门（学习油泵最高电压）。
  5. 停止：先将油门杆调到最小，转速降到怠速后，将油门微调调到停机散热档位，发动机自动冷却——启动电机以较低恒定转速带动压气轮，直至排气温度降至 100℃ 以下自动停机。冷却状态和停机状态均可重新启动。
  6. 运行中将电线、油管等固定牢靠并清理杂物，装防护网；速度快时注意空域与地面安全。因海拔高度、气候条件变化可能导致启动故障，无法解决时联系售后。

十二、储存、润滑与油箱

  • 所有型号可用煤油或柴油作燃料，混加 3%~5% 润滑油（该混合油同时用于轴承润滑系统）。润滑油建议玄云品牌或美孚飞马二号。
  • 润滑油过多→性能下降；过少→轴承润滑不足引发故障，轻则减寿命，重则空中停车。
  • 燃料须清洁无杂质，油箱内部保持干净。拆下发动机或油泵时必须用小段油管封堵油嘴——极微小杂质即可引起油路堵塞或油泵齿轮故障、导致无故熄火。
  • 储存：阴凉干燥通风处，定期试车检测。储存超过 3 个月：为防轴承腐蚀，用燃料充分润滑后垂直放置、密封袋密封；有条件做点火测试更好。
  • 油箱材质可选用玻璃钢或耐油塑料，硬质/软体油箱均可。必须在主油箱与油泵之间搭配防气泡油箱，防止气泡进入发动机引起停车；加油时先排空防气泡油箱内空气再对其加油。加油嘴使用时严禁接地沾黏灰尘。

十三、维护保养

  • 定期检查各连接件与管路紧固情况，清洁发动机表面。
  • 定期检查：外壳有无烧灼变色；固定架是否完好；进气口与叶轮是否完好；油路是否渗漏、油滤是否堵塞。
  • 轴承检查：手动转动转子仔细辨别轴承声音，出现"沙沙"声说明轴承可能进杂质或冷却不当轻微受损——换清洁燃料或油滤后再试；若轴承明显损坏，禁止再次使用发动机，联系售后更换轴承。
  • 每累计运行 25 小时返厂保养（以先到者与保修期并算）：更换轴承、检查机件、清洁油路、更换内部滤芯、清除积碳、重新动平衡、重新试车调整、ECU 数据清零恢复新品状态。返厂时整套电子系统连同发动机本体一起寄回。
  • 关车后的散热直接影响轴承寿命，务必使其充分冷却。若意外熄火，应将遥控器置于关车位置以手动方式散热。
  • 影响涡喷寿命的关键：过热、重摔、超极限使用。
